# Wayfinder changelog

## v0.6.6

- The animated background is now drawn directly on the screen at full sharpness instead of a small picture stretched up, so it is smooth and no longer looks pixelated; the grain over it is much subtler, and long tab names (like Feedback) shrink to fit instead of being cut off
- Long-press selects a file or folder (in the Safe folder and on computer folders too) so you can pick many and move, save or delete them together
- A Sort button on the toolbar (name, date, size, type, either direction); folders now default to most recently changed first
- Files you save, move or download show up in Memories and other gallery apps straight away

## v0.6.5

- Safe folder: a photo or video you open now sits in the whole folder, so you can swipe to the others like any normal folder, and photos have an Edit button that opens them in the Memories editor

## v0.6.4

- Forgot the Safe folder password? After three wrong tries, the unlock screen offers to erase the Safe folder so you can set a new password

## v0.6.3

- Videos and photos open in Memories (Cinema has been merged into it), and a folder of videos opens as a whole folder to swipe through

## v0.6.2

- Wayfinder has your new icon: a tall ship sailing in front of a folder
- At night the animated background gets a stronger wash, so text stays easy to read on dark scenes

## v0.6.1

- Each app's animated scene now has its own drifting symbols (maths signs in Abacus, notes in Echo, arrows in Wayfinder and so on), and the scene is a little clearer while text stays easy to read
- Animated backgrounds reworked after your report: they are drawn at a higher resolution and smoothly at 24 frames a second without slowing the app down, and no longer show horizontal lines

## v0.6.0

- Photos and videos open with the rest of their folder to swipe through, for phone folders and for folders on your computers (Ripple), and Back returns to the folder
- Photos and videos in a computer folder show small previews as you scroll
- Every app window now has the animated scene behind it, in the app's own colour (for example orange water in Abacus, green in Pulse, purple in Scribble), following your Aqua, Bliss or Super look and the real sunrise and sunset. Motion Reduced shows a still picture and Off turns it off
- Help buttons (?) explain the more confusing settings

## v0.5.32

- The new Wayfinder icon: a tall ship in front of a folder, drawn by you
- Fixed a gap above the keyboard in screens with a bottom tab bar: the tab bar now steps aside while you type, so you can see what you are writing

## v0.5.31

- Sharing (Stop) and file jobs (Cancel) also show as a card on the Wonderdesk Launcher's floating button, when it is in use

## v0.5.30

- Fixed tapping a playing video never bringing the controls back

## v0.5.29

- Videos and music on a Ripple computer open straight in Cinema or Bliss Player without asking, and start playing before the file has downloaded

## v0.5.28

- Opening a big file from a Ripple computer no longer copies the whole thing to your phone first: it opens right in the viewer and is read as you watch, so videos start in seconds. Needs the newest Ripple too

## v0.5.27

- Category names on Home are no longer cut off

## v0.5.26

- New settings: open in a chosen folder instead of Home

## v0.5.25

- New sidebar in landscape and on tablets: storage, places, file types, bookmarks, network, safe folder and recycle bin are one tap away. Turn it off in Settings

## v0.5.24

- Text size and accent colour chosen in Control Room now apply here
- New Rotate with the phone switch in Settings. Rotates by default

## v0.5.23

- New browsing settings: show hidden files, grid or list, folders first, grid tile size and reverse sort order

## v0.5.22

- Loading screens now say what they are doing instead of showing a bare spinner
- Wording tidied so no sentence needs a dash

## v0.5.21

- Opening a Ripple file now shows live progress from the first byte with time left, instead of a spinner with no numbers
- Cancel in the progress card or the notification now stops the download at once, even on a stalled connection. A short file that ends early reports the cutoff instead of opening half a file

## v0.5.20

- Ripple file paths stay absolute on the phone side. Photos and other files in the Ripple folder open instead of reporting a relative path as missing
- Copy helper in the open failure dialog reworded. It now reads as two short sentences

## v0.5.19

- A failed file open now pops up with the real reason and one-tap copy, instead of preparing forever and going quiet

## v0.5.18

- Failed file opens now say why out loud instead of preparing forever and going quiet. The real reason shows as a message

## v0.5.17

- Ripple computers open straight into the shared Ripple folder (which always exists) instead of the whole computer

## v0.5.16

- Ripple computers appear automatically through the same-key link. No manual connecting step. If that link can't be used, the one-time system-picker grant is still there as a fallback
- Ripple browser's New folder starts with a name, avoids clashes, and opens the folder it just made

## v0.5.15

- Ripple computers connect through the system folder picker (Android doesn't let apps read another app's file provider directly, which is why the list came back empty): pick a computer once, Wayfinder remembers it and browses its files right here. Files stay on the computer, nothing downloads unless you tap “Save to phone”

## v0.5.14

- Network tab: Ripple computers now open right inside Wayfinder. Browse your PC's files with no downloading, files stay on the computer and stream straight into viewers; long-press a computer for options, "Save to phone" keeps an offline copy only when you ask

## v0.5.13

- Home Recent files is now a toggle (Settings) and sits below Places instead of at the very top
- Network tab: paired Ripple computers appear as shares. Open one in Ripple's file browser

## v0.5.12

- Wayfinder is a file picker for other apps and websites: when something asks for a file (Upload in a browser, Attach in a mail app, Open in an editor), choose Wayfinder to pick from your whole storage, including hidden files, with quick links to Downloads, Pictures and more
- Apps that ask where to save a file (Save as, Export) can use Wayfinder too: choose a folder, name the file and save
- Picking several files at once works, and only files of the type the app asked for are shown

## v0.5.11

- Recent files on Home: documents, downloads and other files changed in the last two weeks, newest first, one tap to open

## v0.5.10

- Rename many files at once: select them and choose “Rename all…”. Use a pattern with a number (Holiday ### gives Holiday 001, 002…) or find and replace, with a live preview of every new name. Extensions are kept
- Copy path (or paths) of the selected files from the menu

## v0.5.9

- Lighter on the battery: in the Super look the drifting sparkles settle after a few seconds without a touch (the next tap wakes them), so a screen you're reading no longer redraws 25 times a second

## v0.5.8

- Changing the look in Control Room now restyles this app's widgets straight away, with no refresh or restart

## v0.5.7

- Widgets: choose the title colour in each widget's settings (automatic, white, dark, Aqua blue, Super pink or gold), on top of the background looks

## v0.5.6

- The Safe folder works with Vault: tap “Use the password in Vault” to unlock with your fingerprint instead of typing, and new Safe passwords can be kept in Vault

## v0.5.5

- Widgets can now match your look: new Bliss blue and Super neon backgrounds, and “Match my Wonderdesk look” follows whatever Control Room is set to

## v0.5.4

- Fixes from a full round of stress testing on every screen

## v0.5.3

- The viewer follows your look: glass title bar and themed background instead of plain black, with PDF pages and text on glass panels
- Videos and music play with the suite's own glass controls (gel play button, ±10 s, scrubber, speed, loop, mute) instead of Android's stock player
- Swipe a photo up or down to close it; pinch zooms around your fingers
- Tap the tab you're already on to glide back to the top of its list
- Nothing required stays hidden: if Android is blocking something the app needs, a slim banner says what and takes you straight to the switch, and Settings › Permissions and access lists everything with its state

## v0.5.2

- Opening a folder slides in from the right and going back slides from the left; the loading spinner only appears if a folder is slow to read
- Viewer: double-tap zoom animates, panning stops at the photo's edges, and one-finger swipes go to the next photo
- Smoother everywhere: new screens, tabs and Settings ease in instead of snapping, and buttons, tabs, chips and switches give a light tap you can feel (following your phone's touch-feedback setting)
- Android's predictive back: the back gesture shows a live preview of where you're going
- New built-in viewer: photos (swipe between them, pinch and double-tap to zoom), video and music, text and code, and PDFs
- Photos, videos and documents in the Safe folder now open right inside Wayfinder, so they never leave it
- Files open in the built-in viewer when the matching Wonderdesk app isn't installed
- Fixed a crash in the Safe folder and network shares when the list changed while it was on screen
- Storage widget shrinks cleanly to small sizes
- Super look: tap sparkles now match Bliss Player: soft glowing sparks with trails, drifting rainbow colours and a faint aurora, instead of big solid circles

## v0.5.1

- Much faster and smoother: the app is now built optimised (the way Play Store apps are), so screens open quicker, scrolling is fluid and the APK is about a quarter of the size
- Screens and lists no longer decode pictures on the main thread, and skip redrawing parts that didn't change

## v0.5.0

- Fixed a crash when Wi-Fi sharing switched itself off
- Storage widget settings: pick any four shortcuts (Downloads, Camera, Pictures, Documents, Music, Movies, Safe folder, Network, Recycle bin, Internal storage) and the background
- Widget shortcuts now work when Wayfinder is already open
- Works properly in landscape: tabs move to a rail at the side so the content keeps its height, and screens that ran out of room now scroll
- If the app ever crashes it says so next time it opens and offers to send a report (only the error, app version and phone model, with file names and links removed). Turn on automatic sending in Control Room › Wonderdesk
- Lists can no longer crash when two items share a name

## v0.4.0

- The Safe folder has its own password, separate from your screen lock and fingerprint, with a hint, a way to change the password, and a way to erase everything
- Safe folder files use a new chunked format: huge files move in and out with real progress and can be cancelled straight away. Older Safe folders are upgraded automatically
- Copy, move, delete, compress, extract and Safe folder jobs run in the background with a progress notification, time left and a working Cancel button; they keep going when you leave the app
- Search can be stopped at any time
- New Storage widget with shortcuts to Downloads, Camera, Documents and the Safe folder
- Files changed a moment ago say “Just now” instead of “0 minutes ago”
- If the app ever crashes or freezes, a report goes to Control Room so it can be shared and fixed
- App icon art is larger and fills its tile without being cut off

## v0.3.1

- Network: browse Windows, Mac, Linux and NAS shares (SMB 2/3), with passwords stored encrypted
- Share this phone over Wi-Fi with a web page anyone can open in a browser (with uploads) and an FTP server for PCs and file managers. Optional password, read-only mode, and it stops by itself when idle
- Safe folder: move files into an encrypted folder that only opens with your fingerprint, face or screen lock
- USB drives and SD cards appear and disappear live, with an Eject shortcut
- Much faster: folders load in the background so scrolling never waits on the disk, categories come straight from Android's media index, search shows results as it finds them, and thumbnails load in parallel
- App icon redrawn so nothing is cut off: round icons fill the space, the rest sit on an Aqua tile
- Smoother and lighter on the battery: the window background no longer animates, tap effects sleep until you tap, and nothing ticks while the app is in the background
- Opening the app no longer waits on Control Room to read the suite look

## v0.3.0

- Full file manager with all files access
- Copy, move, recycle bin, search and ZIP tools
- Opens files in the matching Wonderdesk app
